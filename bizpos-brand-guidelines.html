07 — Usage Rules
Do & Don't
Guidelines for consistent application of brand elements.
✓ Do
  • ✓ Use purple-600 as the primary action color
  • ✓ Pair purple with blue in gradients for CTA buttons
  • ✓ Use Inter at 600–800 weight for headings
  • ✓ Apply rounded-xl (12px) on cards and panels
  • ✓ Maintain dark mode parity for all new components
  • ✓ Use semantic colors (green=success, red=danger)
  • ✓ Add focus rings in purple-500 for accessibility
  • ✓ Keep transitions under 300ms for interactive elements
✗ Don't
  • ✗ Don't use fonts other than Inter
  • ✗ Don't place the logo on busy backgrounds without contrast
  • ✗ Don't use purple for error states — use red
  • ✗ Don't add animations longer than 500ms
  • ✗ Don't mix order-type colors (orange ≠ delivery)
  • ✗ Don't use border-radius less than 6px on interactive elements
  • ✗ Don't use gray-300 text on white — too low contrast
  • ✗ Don't deviate from the 4px spacing grid
